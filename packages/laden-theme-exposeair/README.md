# laden-theme-exposeair

Expose Air Dark by Mark Whittaker (phob1an), GPL-2.0-or-later
(https://store.kde.org/p/2357388, source https://www.opencode.net/phob1an/expose-air).
Shipped unmodified. Laden OS uses the Aurorae window decoration `exposeairdark` by default
(set in laden-desktop-settings `/etc/xdg/kwinrc`), together with the LadenDark colours,
the Breeze application style and Breeze Dark icons, as on ladenx. The Plasma style and the
ExposeAirDark colour scheme are installed for users who want to pick them.
