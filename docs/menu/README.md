# Laden menu (laden-menu 2026.11.09-3, tested on ladenx)

- `laden-menu-favorites.png`: Laden menu (Kickoff, Laden L, favourites grid, Laden category rail)
- `laden-dashboard.png`: Laden Dashboard (fullscreen, Meta+Shift+Space)
- `icons.png`: Laden category icons

Open: **Meta** or click the **L** (top left). Dashboard: the grid icon next to it, or **Meta+Shift+Space**.
Apply for a user: `laden-menu-apply`. Undo: `laden-menu-apply --rollback`.
Remove the categories completely: `sudo pacman -R laden-menu` (stock Plasma menu comes back).
