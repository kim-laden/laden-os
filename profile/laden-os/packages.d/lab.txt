# Lab toolkit for the live image.
# Kali tools come first, then the BlackArch forensic tools people actually open.
# Arch package names win when the same name exists in BlackArch.
# strap.sh is not run. The full BlackArch catalogue is not installed.
# Denial-of-service, keylogger, and backdoor groups are not selected.
#
# Pinned on purpose:
#   jdk-openjdk     one Java for Ghidra and ZAP. Burp Suite ships its own runtime.
#   jdk17-openjdk   Autopsy 4.23 requires Java 17. It does not use the default JDK.
#   opencl-mesa     pinned in packages.x86_64 so hashcat does not stop and ask
#                   which opencl-driver provider to use.
#
# Left out because the package is bulk, not the tool:
#   responder       BlackArch hard-depends on mingw-w64-gcc (~1.2 GiB installed)
#                   for a 4 MiB Python program.
#   seclists        ~1.9 GiB of wordlists. John ships a small list. crunch can
#                   generate more. Add seclists later with pacman if you need it.
#   bloodhound      the desktop app pulls Neo4j and a second JDK (~1 GiB).
#                   The collectors below are the part people run.
#   blackarch-officials, dirb, dirbuster, skipfish, wfuzz, maltego, spiderfoot,
#   empire, powersploit, nishang, mimikatz, beef, set
#                   catalogue filler or tools the ones below replaced.
#                   wfuzz also pulls a wxPython GUI the other fuzzers do not need.
