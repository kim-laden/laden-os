Laden OS

Let's do it!

Unofficial live system based on Arch Linux. It is not Arch Linux.

This session is a fresh overlay. Files you create are discarded on reboot unless you set up the documented persistence option later. The account live has no password and signs in on the local seat only. SSH is masked.

The default wallpaper is the 8K file laden-os-lets-do-it-v2-7680x4320.png. It is AI-upscaled artwork, not a native 8K capture. Other resolutions are in /usr/share/backgrounds/laden/ if you want to switch by hand.

Intel capture stays off. Service identity keys are generated on this boot and are not stored in the image.

Secure Boot is not supported by this unsigned image.
